# Five-minute demo tours

Start at /landing and choose a role. Explain that data stays in this browser, messages/tickets/plans are simulations, and no real card number is needed.

## Cashier

1. 0–1 min: POS search/barcode, add Jasmine Rice, change quantity and select a sample customer.
2. 1–2 min: Hold/resume the cart, complete with demo cash, inspect change and receipt.
3. 2–3 min: Own Profile/Account, personal logs and statement; show unavailable Billing/Email permissions.
4. 3–4 min: Calendar and direct chat; send a harmless sample message and identify the demo auto-reply/shared-login limitation.
5. 4–5 min: Create/reply to a sample ticket, inspect guide progress; show install/offline on production preview if supported.

## Manager

1. 0–1 min: Refund one eligible paid-order unit; explain payment and restock choices.
2. 1–2 min: Create a sample product with opening stock; inspect history and record stock in.
3. 2–3 min: Prepare/send a stock transfer; compare in-transit/received stock and slip.
4. 3–4 min: Compare Dashboard/Sales/Finance using the same date/branch and expand a report table.
5. 4–5 min: Recurring calendar event/all five views; compose an order email and save locally to Sent, reading the nothing-sent confirmation.

## Admin

1. 0–1 min: Settings → General → Data: IndexedDB sizes, quota/persistence, backup reminder/export; explain metadata-only document backups.
2. 1–2 min: Upload a small sample document with expiry, add private/managers notes. Avoid real identity files.
3. 2–3 min: Change demo plan and inspect the invoice; no payment/limits enforcement.
4. 3–4 min: Ctrl/Cmd+K search, notification prefs, FAQ/ticket management, Activity History and filtered CSV.
5. 4–5 min: Maintenance ON, Cashier gating, Admin OFF; inspect Data Health/two confirmed repairs. Finish with Privacy/Licenses and optional roadmap.
